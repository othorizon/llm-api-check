大模型能力与性能测试台

录入任意 OpenAI 兼容端点，一次性测清它的首 token 时延与吞吐、思维链 / 工具调用 / 结构化输出 / 视觉能力， 以及非常规消息格式的兼容性。所有请求由浏览器直接发出，不经过任何中间服务器。

性能测试

  • 流式与非流式的 TTFT（首 token 时延）、输出 token/s、端到端时延、p50 / p95
  • Prompt Cache（上下文缓存）命中率与 TTFT 降幅
  • 多轮测试自动随机化提示词前缀，规避缓存导致的虚高
  • 折算为实时语音对话适配度评级（A / B / C / D）

模型能力测试

  • 思维链是否回传、reasoning_effort 思考等级是否生效
  • 关闭思维链的六种传参写法逐一探测（reasoning_effort: minimal、thinking: disabled、enable_thinking: false 等）
  • 工具调用、tool_choice required 强制调用、指名调用、并行调用、结果回填
  • 结构化输出：json_object、JSON Schema、strict 严格模式、嵌套结构
  • 视觉理解（本地生成图片验证）

消息格式兼容性

  • 开头多条 system、对话中间插入 system、developer 角色
  • 连续多条 user / assistant，以 assistant 结尾的前缀续写
  • 悬空的 tool_calls、孤立的 tool 结果消息
  • 数组形式的 content、最小请求

隐私

本站没有后端接口，不收集任何数据。API Key 与测试结果只保存在你的浏览器本地存储中。
